# コピペ履歴 (Copy History)

コピーした内容を貯めて、ペーストしたい時にサッと取り出せるシンプルなクリップボード履歴ツールです。
ビルド不要の静的な HTML/CSS/JS アプリで、ブラウザだけで動作します。

## 使い方

ローカルで開発サーバーを立てて `index.html` を配信してください（Clipboard API は
`https` またはローカルホストなどの secure context でのみ動作します）。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

もしくは VS Code の Live Server 拡張などでも構いません。

## 機能

- テキストを貼り付けて「履歴に追加」、または「クリップボードから読み込む」ボタンで
  現在のクリップボード内容を履歴に追加
- 「自動監視」をオンにすると、クリップボードの変化を定期的に検知して自動で履歴に追加
- 履歴カードをクリック（またはコピーボタン）でその内容をワンクリックでクリップボードにコピー
- 📌 ピン留めで重要な項目を上部に固定
- 検索ボックスで履歴を絞り込み
- 同じ内容を再度コピーすると重複せず最新として先頭に移動
- 履歴は `localStorage` に保存され、ブラウザを閉じても保持されます
- 「すべて削除」で履歴を一括クリア

## 技術

外部依存なし。プレーンな HTML / CSS / JavaScript のみで実装しています。
