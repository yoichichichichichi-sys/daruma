# daruma

小さなツールを置いているリポジトリです。

- **コピペ帳**: コピーした内容を貯めて、ペーストしたい時にサッと取り出せるクリップボード履歴ツール（`web/`・`android/`・`ios/`）
- **Daruma DAW**: 日本語で話しかけて操作できるブラウザ DAW ＋ 作曲アシスタント（`daw/`）

## このリポジトリの構成

- **`daw/`** — DAW オペレーター＆作曲アシスタント（ビルド不要の HTML/CSS/JS）。
  「おまかせで切ない曲を8小節」「コード Am F C G」「ベースをウォーキングで」のような指示で
  曲を作り、MIDI で外部 DAW に持ち出せます。Claude API キーを設定すると自由な指示や作曲相談も可能。
  詳細は [`daw/README.md`](daw/README.md) を参照してください。

- **`web/`** — ブラウザだけで動く簡易プロトタイプ（ビルド不要の HTML/CSS/JS）。
  クリップボードから手動で取り込む形の最初の試作版です。詳細は
  [`web/README.md`](web/README.md) を参照してください。
- **`android/`** — 本命のネイティブアプリ（Kotlin）。他のアプリでコピーした
  瞬間に自動で履歴に残り、ホーム画面のウィジェットで上下にフリックして
  呼び出せます。詳細は [`android/README.md`](android/README.md) を参照してください。
- **`ios/`** — iOS 版（Swift/SwiftUI + WidgetKit）。iOS はバックグラウンドでの
  クリップボード読み取りが禁止されているため、「アプリを開いた瞬間に取り込む」
  ＋「ウィジェットは矢印ボタンで前後に送る」という形になっています。詳細は
  [`ios/README.md`](ios/README.md) を参照してください。

いずれの native アプリもこのセッションの実行環境（Android SDK / Xcode に
ネットワーク・OS 制約でアクセスできないクラウド Linux コンテナ）では
コンパイル・実機確認ができていません。Android Studio / Xcode でビルドして
確認してください。
