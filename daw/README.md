# Daruma DAW — Studio Pro のオペレーター & 作曲アシスタント

**Fender Studio Pro** を使った曲作りの横に置く、ブラウザで動く相棒です。

- **Studio Pro のオペレーター**: 日本語で「録音して」「トラック3をソロ」と言うと、Mackie Control 経由で Studio Pro 本体を操作します。
  Claude を有効にすると、Studio Pro の操作方法の質問にも答えます（自分のマニュアル抜粋やメモを渡すと、それを優先して答えます）。
- **アレンジと MIDI アイデア**: コード進行・メロディ・ベース・ドラムをスケッチ用の DAW で作って聴き、MIDI で Studio Pro に持ち込めます。
- **参考曲ライブラリ**: プロの曲などの MIDI を読み込ませると、その曲の進行・グルーヴ・ベースの動き・バッキングのリズム・
  メロディのリズムと輪郭を学び、今の曲のキーとコードに当てはめて使います。いつもの手癖から外れたアレンジの幅を広げるための機能です。

ビルド不要の静的 HTML/CSS/JS（ES Modules）です。

**Windows**: `daw` フォルダの **`start.bat` をダブルクリック**するとブラウザで開きます（Windows 標準の PowerShell だけで動くので Python は不要）。
黒い画面を閉じると止まります。

**Mac / Linux / Python がある場合**:

```bash
cd daw
python3 -m http.server 8000   # または npm start
# http://localhost:8000 を開く
```

`index.html` をダブルクリックして直接開くと（`file://`）、ブラウザの制限で動きません。必ず上のどちらかで開いてください。

## できること

### DAW 本体
- 複数トラック（ピアノ／エレピ／パッド／ストリングス／プラック／リード／シンセベース／ドラム）を Web Audio の内蔵シンセで再生
- ピアノロール: クリックでノート入力、ドラッグで長さ、クリックで削除、他トラックのゴースト表示
- テンポ・キー・小節数・ループ・メトロノーム、トラックごとの音量・ミュート・ソロ
- Undo / Redo（Ctrl+Z / Ctrl+Shift+Z）、Space で再生／停止
- 自動保存（localStorage）、プロジェクトの .json 保存／読み込み
- **MIDI 書き出し**（SMF Type 1。コード名はマーカーとして入ります）→ Logic / Ableton / Cubase / FL Studio などに読み込めます
- **Web MIDI 出力**（Chrome / Edge）: IAC ドライバや loopMIDI などの仮想ポートを選ぶと、再生中のノートを外部 DAW の音源へ送ります

### オペレーター（日本語コマンド）
API キー無しで、ルールベースで次のような指示が通じます。「。」や改行で区切って複数の指示を一度に出せます。

| 例 | 動作 |
|---|---|
| `テンポ120` / `テンポを上げて` / `キーをAmに` / `ハ短調にして` / `16小節にして` | 曲の設定 |
| `王道進行で` / `切ない進行にして` / `おしゃれなコード進行の提案` | 定番進行の適用・提案 |
| `コード Am F C G` / `進行 I V vi IV アルペジオで` / `コード追加 Em` / `次のコードは？` | コード入力・次のコードの提案 |
| `メロディを作って`（`高めで`・`細かく`・`シンプルに`）/ `ベースをウォーキングで` / `ドラムを4つ打ちで` | フレーズ生成 |
| `おまかせで切ない曲を16小節` | コード・メロディ・ベース・ドラムを一度に作る |
| `メロディを+2移調` / `ベースを1オクターブ下げて` / `メロディをクオンタイズ` / `ドラムをミュート` / `ベースの音量70` | 編集 |
| `再生` / `停止` / `3〜4小節をループ` / `分析して` / `MIDI書き出し` / `元に戻す` | その他 |

`ヘルプ` と入力すると一覧が出ます。

### 作曲アシスタント
- **定番進行**: 王道進行、小室進行、カノン、Just The Two Of Us、エピック、アンダルシア、12小節ブルースなど。今のキーに合わせたコード名に直して入れます
- **次のコードの提案**: 機能和声（トニック／サブドミナント／ドミナント）に沿った候補を理由付きで出します。ピアノロール上段のコード欄をクリックすると、その小節に入れる候補が出ます
- **自動生成**: ボイスリーディングを考えたコードのボイシング、強拍にコードトーンを置き 2 小節のモチーフを繰り返すメロディ、5 種類のベース、8 種類のドラムパターン（4 小節ごとにフィル）
- **分析**: キー外の音、コードと半音でぶつかる長い音、音域の広すぎ、ノートの分布から推定したキーなどを指摘し、「次の一手」をボタンで出します

### 参考曲ライブラリ（プロの曲の MIDI から学ぶ）
「参考曲」ボタン（または「⋯ → 参考曲ライブラリ」）に MIDI ファイルをドロップします（複数可）。1 曲ごとに次を自動で取り出します。

| 抽出するもの | 中身 | 使い方の例 |
|---|---|---|
| キー・テンポ | ノートの分布と、フレーズの終わり・曲の最後のコードから長調/短調を判定 | — |
| コード進行 | 半小節単位でコードを推定し、**主音からの距離**で保存（キーに依存しない） | `参考曲から進行` / `参考曲を組み合わせて新しい進行`（複数曲の流れを学習して新しい進行を作る） |
| ドラムのグルーヴ・フィル | 16 ステップのパターン（キック・スネア・ハット等の役割ごと） | `参考曲「ファンク」のドラムで` |
| ベースの動き | リズム＋「その時のコードのルートから何度か」 | `参考曲のベースで`（今のコードで弾き直し、3 度や 7 度の種類はコードに合わせる） |
| バッキングのリズム | コードを鳴らすタイミングと長さ | `参考曲のバッキングで`（ボイシングは今のコードで作る） |
| メロディのリズムと輪郭 | 2 小節ごとのリズムと「上がる・下がる・跳ぶ」の動き | `参考曲のメロディで`（音は今のキーとコードに合わせて作り直す） |

- パート（ドラム・ベース・メロディ・コード）は、トラック名・GM 音色・音域・和音の多さから自動判定します
- タグ（例: `ファンク, 90s, バラード`）を付けると `参考曲「90s」の型でアレンジ` のように絞り込めます
- `seed` を変えるたび（同じ指示をもう一度）に別の組み合わせになるので、何案か作って比べられます
- 長調の参考曲を短調の曲に使うときは平行調として読み替えます
- 「⋯ → MIDI ファイルを開いて編集」で、MIDI をそのままトラックに展開して中身を見ることもできます
- MIDI ファイルはブラウザの中だけで解析し、抽出した型だけを localStorage に保存します（外部には送りません）。
  ライブラリは .json に保存・読み込みできるので、別の PC への持ち運びやバックアップに使ってください
- 読み込む MIDI は、購入した MIDI パック・自作曲・利用が許可されたデータなど、使ってよいものにしてください。
  このツールは型（リズム・音程の関係）を組み替えて使い、元のメロディをそのまま書き出すことはしません

#### オーディオの曲から参考曲を作る（Studio Pro のステム分離 → MIDI 化）
MIDI データが手元に無い曲も、Studio Pro のステム分離とオーディオ→MIDI 変換を使えば参考曲にできます
（機能の名前やメニューの場所は Studio Pro のバージョンによって違う可能性があります）。

1. 曲のオーディオを Studio Pro に読み込み、**ソングのテンポを曲に合わせ、1 小節目の頭を曲の頭拍にそろえる**。
   ここがずれると、小節ごとのパターンやコードの区切りがずれて学習の質が落ちます
2. ステム分離でドラム・ベース・ボーカル・その他に分ける
3. 各ステムを MIDI に変換する（ドラムはドラム用、ベース・ボーカルは単音のメロディ用の変換があればそれを使う）
4. MIDI パートをステムごとに `.mid` で書き出す。ファイル名に **ステム名を入れる**:
   `曲名_drums.mid` / `曲名_bass.mid` / `曲名_vocals.mid` / `曲名_other.mid`（`ドラム` `ベース` `ボーカル` `その他` などの日本語も可）
5. 4 つをまとめて参考曲ライブラリにドロップ → 同じ曲名のファイルが **1 曲として** 読み込まれる

変換した MIDI は手で打ち込んだ MIDI より荒れているので、読み込み時に自動で整えます。

- ごく短い音・ごく弱い音（変換ノイズ）を捨てる
- ベース・ボーカルの細切れになった同じ音をつなぎ、同時に鳴った音は 1 音にする（ベースは最低音、ボーカルは最高音）
- ドラムの音高が GM 配置でない場合、「一番低い音 = キック、一番高い音 = ハット、中音域で一番多い音 = スネア」と推定して割り当て直す
- テンポ情報が無いファイルは 120BPM として解析する（小節の位置は MIDI の拍で決まるので、手順 1 でそろえてあれば問題ありません）

一覧には「細切れ◯・ノイズ◯音を整理」「ドラムの音高を推定して割り当て」のように何をしたかが表示されます。
変換精度の目安は **ドラム・ベース ＞ ボーカル ＞ その他（和音）** です。和音の変換は崩れやすいので、
コード進行はベースの動きも手がかりにして推定しています。

### Fender Studio Pro の操作（Mackie Control）
アプリ → 仮想 MIDI ポート → Studio Pro の経路で、標準の Mackie Control (MCU) 信号を送ります。

#### Windows でのつなぎ方
1. [loopMIDI](https://www.tobias-erichsen.de/software/loopmidi.html) をインストールし、「+」で次の 3 つのポートを作る

   | ポート名 | 向き | 用途 |
   |---|---|---|
   | `DarumaCtrl` | アプリ → Studio Pro | Mackie Control の操作信号 |
   | `DarumaFeedback` | Studio Pro → （どこにもつながない） | Studio Pro が返すランプ・フェーダー情報の逃がし先 |
   | `DarumaNotes` | アプリ → Studio Pro | 再生した音を Studio Pro の音源で鳴らす・録音する（任意） |

   loopMIDI は Windows の起動時に自動で立ち上がるようにしておくと楽です（ポートは loopMIDI が動いている間だけ存在します）。
   **Studio Pro より先に loopMIDI を起動**してください（後から作ったポートは Studio Pro を再起動するまで見えないことがあります）。
2. Studio Pro の外部デバイス設定（Studio One 系では「Studio Pro → オプション → 外部デバイス → 追加」）で **Mackie Control** を追加し、
   **受信元 = `DarumaCtrl`、送信先 = `DarumaFeedback`（または なし）** にする。
   送信先を `DarumaCtrl` にすると、Studio Pro の返す信号が自分に戻ってループするので避けてください
3. このアプリを **Chrome か Edge** で開き（`http://localhost:8000`）、MIDI の使用を許可する。
   「⋯ → 設定 → Mackie Control 用ポート」で `DarumaCtrl` を選ぶ。音も送るなら「音を送る出力先」で `DarumaNotes` を選び、
   Studio Pro の音源トラックの入力を `DarumaNotes` にする
4. 「Studio Pro」ボタンのリモート画面か、チャットで操作する

（Mac の場合は「Audio MIDI 設定 → IAC ドライバ」で同じ名前のポートを作れば、あとは同じです。）

| チャットの例 | 動作 |
|---|---|
| `スタジオプロで再生` / `停止` / `録音` / `巻き戻し` / `ループ` / `クリック` / `マーカー` / `保存` / `元に戻す` | トランスポート・各ボタン |
| `スタジオプロのトラック3をミュート`（`ソロ` / `選択` / `録音待機`） | チャンネルストリップのボタン |
| `スタジオプロのトラック2の音量を-6dB` / `スタジオプロのマスターの音量を80%` | フェーダー |
| `スタジオプロのバンクを右へ` / `バンクをリセット` | 8 トラック単位の表示切替 |

- トラック番号は Studio Pro のミキサーでの並び順です。MCU は 8 トラックずつ（バンク）扱うので、9 以降はアプリが自動でバンクを送ります。
  バンク位置はアプリ側の推定なので、Studio Pro 側で手動でバンクを動かしたら「バンク位置をリセット」で揃えてください
- フェーダーの dB 値は MCU の一般的なカーブでの目安で、Studio Pro の表示と少しずれることがあります
- 一部のボタン（マーカー、F1〜F8 等）の割り当ては Studio Pro 側の Mackie Control 実装に従います
- プラグインの挿入や細かい編集は MCU ではできないので、Claude に手順を聞いてください

**作ったフレーズを Studio Pro に持ち込む**: 「MIDI 書き出し」（全体）か「⋯ → 選択中のトラックだけ MIDI 書き出し」
（チャットなら `ベースだけMIDI書き出し`）で .mid を作り、Studio Pro のアレンジビューへドラッグします。
または「設定 → 音を送る出力先」に `DarumaNotes` を選び、Studio Pro の音源トラックの入力をそのポートにすると、
アプリで再生した音を Studio Pro の音源で鳴らしたり、そのまま録音したりできます。

### Claude 連携（任意）
メニュー「⋯ → 設定」で Anthropic の API キーを入れて「Claude を使う」をオンにすると、
Claude がこのアプリのすべての操作（スケッチ DAW の編集・参考曲ライブラリ・Studio Pro のリモート操作）をツールとして使い、

- 「サビっぽく盛り上げて」「参考曲の 90s っぽさを混ぜて別案を 3 つ」「このメロディ、もう少し跳躍を減らせる？」のような作曲の相談
- 「Studio Pro でサイドチェインのやり方は？」「録音して、終わったら止めて」のような Studio Pro の操作・質問

に、実際に編集・操作しながら答えます。設定の「Studio Pro の参考資料」に、マニュアルの抜粋や自分のショートカット設定、
よく使う手順のメモを貼ると、操作の質問にそれを優先して答えます（バージョンによって違う可能性がある箇所はそう断って答えます）。

- モデル: Claude Opus 5.5（既定）／ Sonnet 5.5 ／ Haiku 5.5
- SDK は `@anthropic-ai/sdk` を esm.sh から読み込みます（初回のみネットワークが必要）
- Opus / Sonnet では、安全分類器で応答が断られたときにサーバー側で別モデルへ切り替える fallback を有効にしています
- API キーは**このブラウザの localStorage にだけ**保存され、Anthropic API にのみ直接送信されます。
  ブラウザから直接 API を呼ぶ構成なので、共用 PC や公開サーバーでは使わないでください

## 構成

```
daw/
├── index.html / style.css
├── js/
│   ├── app.js        画面・ピアノロール・チャット・ライブラリ／リモート画面
│   ├── engine.js     Web Audio シンセ、先読みスケジューラ、Web MIDI 出力
│   ├── project.js    曲データのモデル、Undo/Redo
│   ├── actions.js    DAW 操作の一覧（オペレーターと Claude の共通の入口）
│   ├── operator.js   日本語コマンドの解析
│   ├── claude.js     Claude のツール呼び出しループ
│   ├── assistant.js  分析と提案
│   ├── generate.js   コード／メロディ／ベース／ドラムの生成
│   ├── theory.js     音名・スケール・コード・ディグリー・定番進行
│   ├── library.js    参考曲の解析（パート判定・コード検出・型の抽出）と型からの生成
│   ├── studiopro.js  Studio Pro のリモート操作（Mackie Control）
│   └── midi.js       Standard MIDI File の読み書き
└── tests/daw.test.mjs
```

すべての編集は `actions.js` のアクションを通るので、オペレーターで出来ることと Claude に出来ることは
同じです。新しい操作を足すときはここにアクションを 1 つ追加すれば、両方から使えるようになります。

## テスト

```bash
cd daw && npm test    # Node.js 18+、依存パッケージ不要
```

音楽理論、フレーズ生成、アクション、日本語コマンドの解析、MIDI ファイルの読み書き、
参考曲の解析と型の当てはめ、Mackie Control のメッセージ、Claude のツール定義を確認します。

## 制限
- 拍子は 4/4 固定、1 曲 256 小節まで
- 内蔵シンセは簡易的なものです。本格的な音作りは MIDI 書き出しか Web MIDI 出力で外部 DAW へ
- Web MIDI（Studio Pro の操作・音の送信）は Chrome / Edge などの対応ブラウザのみ
- 参考曲は 4/4 として解析します。コード検出は自動推定なので、テンションの多い曲や転調する曲では目安程度です
- オーディオ（WAV/MP3）は読み込めません。Studio Pro などで MIDI にしてから読み込んでください
- Studio Pro との接続は、Studio Pro 実機ではまだ確認できていません（MCU の標準仕様どおりの信号を送ることはテストで確認済み）
