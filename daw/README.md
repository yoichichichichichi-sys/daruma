# Daruma DAW — DAW オペレーター & 作曲アシスタント

ブラウザだけで動く小さな DAW です。日本語で話しかけて操作し、作曲の手伝いも頼めます。
ビルド不要の静的 HTML/CSS/JS（ES Modules）です。

```bash
cd daw
python3 -m http.server 8000   # または npm start
# http://localhost:8000 を開く
```

## できること

### DAW 本体
- 複数トラック（ピアノ／エレピ／パッド／ストリングス／プラック／リード／シンセベース／ドラム）を Web Audio の内蔵シンセで再生
- ピアノロール: クリックでノート入力、ドラッグで長さ、クリックで削除、他トラックのゴースト表示
- テンポ・キー・小節数・ループ・メトロノーム、トラックごとの音量・ミュート・ソロ
- Undo / Redo（Ctrl+Z / Ctrl+Shift+Z）、Space で再生／停止
- 自動保存（localStorage）、プロジェクトの .json 保存／読み込み
- **MIDI 書き出し**（SMF Type 1。コード名はマーカーとして入ります）→ Logic / Ableton / Cubase / FL Studio などに読み込めます
- **Web MIDI 出力**（Chrome / Edge）: IAC ドライバや loopMIDI などの仮想ポートを選ぶと、再生中のノートを外部 DAW の音源へ送ります

### オペレーター（日本語コマンド）
API キー無しで、ルールベースで次のような指示が通じます。「。」や改行で区切って複数の指示を一度に出せます。

| 例 | 動作 |
|---|---|
| `テンポ120` / `テンポを上げて` / `キーをAmに` / `ハ短調にして` / `16小節にして` | 曲の設定 |
| `王道進行で` / `切ない進行にして` / `おしゃれなコード進行の提案` | 定番進行の適用・提案 |
| `コード Am F C G` / `進行 I V vi IV アルペジオで` / `コード追加 Em` / `次のコードは？` | コード入力・次のコードの提案 |
| `メロディを作って`（`高めで`・`細かく`・`シンプルに`）/ `ベースをウォーキングで` / `ドラムを4つ打ちで` | フレーズ生成 |
| `おまかせで切ない曲を16小節` | コード・メロディ・ベース・ドラムを一度に作る |
| `メロディを+2移調` / `ベースを1オクターブ下げて` / `メロディをクオンタイズ` / `ドラムをミュート` / `ベースの音量70` | 編集 |
| `再生` / `停止` / `3〜4小節をループ` / `分析して` / `MIDI書き出し` / `元に戻す` | その他 |

`ヘルプ` と入力すると一覧が出ます。

### 作曲アシスタント
- **定番進行**: 王道進行、小室進行、カノン、Just The Two Of Us、エピック、アンダルシア、12小節ブルースなど。今のキーに合わせたコード名に直して入れます
- **次のコードの提案**: 機能和声（トニック／サブドミナント／ドミナント）に沿った候補を理由付きで出します。ピアノロール上段のコード欄をクリックすると、その小節に入れる候補が出ます
- **自動生成**: ボイスリーディングを考えたコードのボイシング、強拍にコードトーンを置き 2 小節のモチーフを繰り返すメロディ、5 種類のベース、8 種類のドラムパターン（4 小節ごとにフィル）
- **分析**: キー外の音、コードと半音でぶつかる長い音、音域の広すぎ、ノートの分布から推定したキーなどを指摘し、「次の一手」をボタンで出します

### Claude 連携（任意）
メニュー「⋯ → 設定」で Anthropic の API キーを入れて「Claude を使う」をオンにすると、
Claude が DAW のすべての操作（上のアクション＋ノートの直接入力）をツールとして使い、
「サビっぽく盛り上げて」「2小節目の頭にキメを入れて」「このメロディ、もう少し跳躍を減らせる？」のような
自由な指示や作曲の相談に、実際に曲を編集しながら答えます。

- モデル: Claude Opus 5.5（既定）／ Sonnet 5.5 ／ Haiku 5.5
- SDK は `@anthropic-ai/sdk` を esm.sh から読み込みます（初回のみネットワークが必要）
- Opus / Sonnet では、安全分類器で応答が断られたときにサーバー側で別モデルへ切り替える fallback を有効にしています
- API キーは**このブラウザの localStorage にだけ**保存され、Anthropic API にのみ直接送信されます。
  ブラウザから直接 API を呼ぶ構成なので、共用 PC や公開サーバーでは使わないでください

## 構成

```
daw/
├── index.html / style.css
├── js/
│   ├── app.js        画面・ピアノロール・チャット
│   ├── engine.js     Web Audio シンセ、先読みスケジューラ、Web MIDI 出力
│   ├── project.js    曲データのモデル、Undo/Redo
│   ├── actions.js    DAW 操作の一覧（オペレーターと Claude の共通の入口）
│   ├── operator.js   日本語コマンドの解析
│   ├── claude.js     Claude のツール呼び出しループ
│   ├── assistant.js  分析と提案
│   ├── generate.js   コード／メロディ／ベース／ドラムの生成
│   ├── theory.js     音名・スケール・コード・ディグリー・定番進行
│   └── midi.js       Standard MIDI File 書き出し
└── tests/daw.test.mjs
```

すべての編集は `actions.js` のアクションを通るので、オペレーターで出来ることと Claude に出来ることは
同じです。新しい操作を足すときはここにアクションを 1 つ追加すれば、両方から使えるようになります。

## テスト

```bash
cd daw && npm test    # Node.js 18+、依存パッケージ不要
```

音楽理論、フレーズ生成、アクション、日本語コマンドの解析、MIDI ファイルの構造、
Claude のツール定義を確認します。

## 制限
- 拍子は 4/4 固定、1 曲 256 小節まで
- 内蔵シンセは簡易的なものです。本格的な音作りは MIDI 書き出しか Web MIDI 出力で外部 DAW へ
- Web MIDI は Chrome / Edge などの対応ブラウザのみ
