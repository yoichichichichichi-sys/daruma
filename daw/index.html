    オペレーター

    ルールモード

    設定

    Claude（任意）

    API キーを入れると、自由な言い方の指示や作曲の相談を Claude が DAW を操作しながらこなします。 キーはこのブラウザの localStorage にだけ保存され、Anthropic API にのみ送信されます。

    MIDI 出力（外部 DAW を鳴らす）

    IAC ドライバ（Mac）や loopMIDI（Windows）などの仮想 MIDI ポートを選ぶと、再生中のノートを Logic / Ableton Live / Cubase などに送れます。ドラムは ch10、その他は ch1 から順に割り当てます。
