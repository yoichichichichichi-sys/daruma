    オペレーター

    ルールモード

    設定

    Claude（任意）

    API キーを入れると、自由な言い方の指示や作曲の相談を Claude が DAW を操作しながらこなします。 キーはこのブラウザの localStorage にだけ保存され、Anthropic API にのみ送信されます。

    Studio Pro リモート（Mackie Control）

    仮想 MIDI ポートを 1 つ選びます。Studio Pro 側では「Studio Pro → オプション → 外部デバイス → 追加」で Mackie Control を追加し、受信元／送信先にこのポートを指定してください（メニュー名はバージョンにより異なることがあります）。 下の「音を送る出力先」とは別のポートにしてください。

    音を送る出力先（外部 DAW の音源を鳴らす）

    IAC ドライバ（Mac）や loopMIDI（Windows）などの仮想 MIDI ポートを選ぶと、再生中のノートを Logic / Ableton Live / Cubase などに送れます。ドラムは ch10、その他は ch1 から順に割り当てます。

    参考曲ライブラリ

    プロの曲などの MIDI ファイルを読み込むと、キー・コード進行・ドラムのグルーヴ・ベースの動き・バッキングのリズム・ メロディのリズムと輪郭を抜き出して貯めます。オペレーターに「参考曲の型でアレンジ」「参考曲から進行」などと頼むと、 今の曲のキーとコードに当てはめて使います。タグ（例: ファンク, 90s, バラード）を付けると「参考曲『ファンク』のドラムで」のように絞り込めます。 ファイルはこのブラウザの中だけで解析・保存し、外部には送りません。
