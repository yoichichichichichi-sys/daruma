# 引継ぎメモ（studio-pro-assistant）

このプロジェクトを始めた最初の会話（2026 年 10 月）の内容をまとめたもの。
新しい会話・新しいセッションで開発を続けるときは、まずこれを読む。
claude.ai のプロジェクト機能を使う場合は、このファイルをプロジェクトのナレッジに入れておくと文脈を引き継げる。

## 1. 目的（ユーザーの要望）

- メインで使っている DAW **Fender Studio Pro** は機能が多いので、**操作を代わりにやってくれる／やり方を教えてくれるオペレーター**が欲しい
- **作曲・アレンジのアシスタント**: コード進行、メロディ、ベース、ドラムなどの MIDI アイデアを出す
- **プロの曲のデータを学習させて、アレンジの幅を広げたい**。データは Studio Pro のステム分離 → MIDI 化で用意する
- **精度が大事**（手軽さより精度）

## 2. ユーザーの環境

- OS: **Windows 11**
- DAW: Fender Studio Pro。ほかに EZdrummer 3、EZkeys 2、Kemper Profiler、SpectraLayers などを持っている様子
- ブラウザ: Chrome
- 仮想 MIDI: **loopMIDI** で次の 3 ポートを作る（ポートは loopMIDI 起動中のみ存在。Studio Pro より先に起動）

  | ポート | 向き | 用途 |
  |---|---|---|
  | `DarumaCtrl` | アプリ → Studio Pro | Mackie Control の操作信号 |
  | `DarumaFeedback` | Studio Pro → どこにもつながない | MCU のフィードバックの逃がし先（ループ防止） |
  | `DarumaNotes` | アプリ → Studio Pro | アプリの演奏を Studio Pro の音源で鳴らす（任意） |

- Studio Pro の外部デバイス: **Mackie Control**、受信元 = `DarumaCtrl`、送信先 = `DarumaFeedback`
- アプリの起動: `start.bat` をダブルクリック（PC の Python が壊れていた。`C:\Python314` が無く、`python` は Microsoft Store のダミー。
  そのため Python 不要の PowerShell サーバーを用意した）。`start.bat` はダウンロード直後だと「発行元を確認できません」の警告が出る → 「実行」で OK、またはプロパティで「許可する」

## 3. できていること

- **スケッチ用 DAW**（ブラウザ）: 複数トラック、内蔵シンセ、ピアノロール、ループ、Undo/Redo、自動保存、MIDI 読み書き
- **日本語オペレーター**（API キー不要のルールベース）: 「おまかせで切ない曲を8小節」「コード Am F C G」「ベースをウォーキングで」「メロディを+2移調」「ベースだけMIDI書き出し」など
- **作曲アシスタント**: 定番進行 13 種、機能和声に沿った次のコード提案、ボイスリーディング付きのボイシング、メロディ・ベース・ドラム生成、曲の分析
- **参考曲ライブラリ**: MIDI を読み込み、キー・コード進行（キー非依存）・ドラムのグルーヴ/フィル・ベースの動き・バッキングのリズム・メロディのリズムと輪郭を抽出。
  今の曲のキーとコードに当てはめて生成（「参考曲から進行」「参考曲を組み合わせて新しい進行」「参考曲「タグ」のドラムとベースで」）
  - ステム別ファイル（`曲名_drums.mid` / `_bass` / `_vocals` / `_other`）は 1 曲にまとめる
  - 音声から変換した MIDI のクリーンアップ（ノイズ除去、細切れ結合、単音化、GM でないドラム音高の推定）
- **Studio Pro リモート**（Mackie Control）: トランスポート、ループ、クリック、マーカー、保存、元に戻す、トラックの選択/ミュート/ソロ/録音待機、フェーダー、バンク自動切替
- **Claude 連携**（任意、API キーを設定画面で入れる）: 全アクションをツールとして使う。Studio Pro の操作方法の質問にも答える（設定の「参考資料」欄にマニュアル抜粋などを貼ると優先して使う）。OS 設定で Windows/Mac のショートカット表記を切替
- 自動テスト 23 件

## 5. 決めたこと・方針

- **YouTube 等からの音源ダウンロードツールは作らない**（利用規約・著作権法上の問題）。参考曲の入手は、購入音源（mora、OTOTOY、Bandcamp など）、手持ち CD、
  公式マルチトラック（Cambridge Music Technology のライブラリ、リミックスコンテスト）、市販 MIDI を使う、とユーザーと合意
- **音声ファイルを直接取り込む機能（ブラウザ内の音声→MIDI 変換）は不要**とユーザーが判断（精度は Studio Pro のステム分離の方が上のため）
- 参考曲のメロディをそのまま複製しない。借りるのはリズム・輪郭・コード上の音程まで
- Studio Pro のメニュー名はバージョンで違う可能性があるので断定しない
