🎛️ UAFX Web Control

UAFX ペダルを PC のブラウザから操作するための非公式コントローラー

未接続

プリセット

コントロール

「Learn」を押してからペダル本体のノブを回すと、受信した MIDI CC 番号がそのコントロールに割り当てられます（ペダルが CC を送信する場合のみ）。

Web MIDI 接続

ペダルの USB-C を PC に直結（またはUSB MIDI インターフェース経由）して接続します。Chrome / Edge 推奨。

手動送信

スイープは、ドキュメントにない CC がどのパラメーターに効くかを調べるためのものです。音量に注意してください。

Web Bluetooth GATT エクスプローラー

Web Bluetooth は、事前に申告したサービス UUID にしかアクセスできません。スマホの nRF Connect などでペダルのサービス UUID を確認し、下に入力してください（カンマ区切り）。
※ 接続中はスマホの UAFX Control アプリを終了しておいてください。

WebUSB デスクリプタビューア

USB-C 直結時にペダルが何として認識されているか（ベンダー ID・インターフェース構成）を確認します。オーディオ / MIDI クラスのインターフェースはブラウザの保護対象のため WebUSB からは開けません。MIDI として見えている場合は「MIDI」タブを使ってください。

未選択

デバイスプロファイル (JSON)

ノブとプリセットをどのメッセージに割り当てるかを定義します。同梱のプロファイルの CC 番号は仮の値です。お使いのペダルのマニュアル（MIDI 実装表）か「MIDI」タブでの調査結果に合わせて書き換えてください。書式は README を参照。
